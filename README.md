# KingdomTrainer · 玩家反馈与进展

这里仅维护玩家反馈公示网站，与软件发行仓库分开。不会发布修改器二进制、更新检测文件、游戏源码、玩家日志或附件。

新反馈从软件进入，自动归类为私有草稿；作者确认摘要并填写回复后才公开。评分与问题独立处理，五星反馈也可能包含功能问题。

网页与公开数据在同一 GitHub Pages 地址提供；访客不用登录。原始附件继续只保存在 Tally 后台。

自动同步只读取已公开字段；不使用 Tally 私钥、GitHub个人令牌或 AI API。同步失败会终止发布，保留上一次成功页面。

GitHub Pages 是备用静态快照，调度可能延迟，不作为实时状态的依据。页面显示实际快照时间，提供刷新按钮。工作流使用标准 Ubuntu runner，产物只保留1天。

腾讯 EdgeOne Makers 版本：`npm run build:edge` 生成 `edge-site/`，支持直接上传。HTML、公开数据接口同源；只读函数向固定作者后台读取已审核公开字段，10秒内复用一次结果，页面每30秒自动刷新。失败显示未同步，不把旧状态冒充最新状态。服务端不转发访客凭据，不提供提交反馈入口，不包含私有草稿、日志、附件、邮箱或管理权限。

大陆正式访问需要自行绑定可用域名；默认域名/签名预览链有平台限制，不能当长期入口。域名购买和备案不包含在免费托管费用里。本仓库不包含腾讯云、Tally或GitHub密钥，也不包含游戏修改功能。
